# Bundled fonts

Latin and Latin Extended variable WOFF2 subsets of Host Grotesk and Geist
Mono, copied from `frontend/public/fonts/` (originally
@fontsource-variable/host-grotesk and @fontsource-variable/geist-mono 5.3.0).
The landing page is English-only, so the Cyrillic, Vietnamese, and symbol
subsets the app ships are left out. Both fonts use the SIL Open Font License
in the accompanying LICENSE files.
